# UAL Counterfactual Lab

Local implementation of the Longaeva Phase 1 proposal, with a monthly airline
scenario prototype, public-data pipelines and independently checked research
components. Fitted behavior, full financial reconciliation and proposal-wide
validation remain work in progress.

The application is in [UAL_Counterfactual_Engine_v1](UAL_Counterfactual_Engine_v1/README.md).
See its [proposal checklist](UAL_Counterfactual_Engine_v1/docs/proposal_delivery.md)
for coverage and [local development notes](UAL_Counterfactual_Engine_v1/docs/local_development.md)
for Git and verification commands.
